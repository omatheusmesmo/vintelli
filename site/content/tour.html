The screenshots on this page are rendered HTML from a terminal capture, not a real terminal. The site workflow starts the TUI in tmux at 160 by 45 cells, takes each pane with its colors and converts it to HTML. Fonts, cursor and the exact glyph shapes of your own terminal will differ.

Both shipped themes are shown for each screen: darcula (the classic IntelliJ Darcula chrome) and dark (the default, New UI Dark chrome). Press Ctrl+T to switch between them in the TUI.

Project

The default layout: the project pane on the left, the editor in the middle, and the tool window stripes around it. Alt+1 focuses the project pane.

Search Everywhere

Ctrl+P opens the command palette, the stand-in for IntelliJ's Search Everywhere. It lists every action with its active chord and filters by label or action id.
