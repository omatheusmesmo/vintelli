Pre-release · open source · JDK 25

IntelliJ IDEA, in your terminal.

A terminal IDE for Java with the layout, keys and colors you already know. It runs with open tooling only. IntelliJ IDEA is an optional extra.

Standalone first

Vintelli works without IntelliJ IDEA. Every capability has a standalone provider, and IDEA only adds its providers for Run, Terminal, Problems and call hierarchy when you connect it.

Ctrl+Space

Language support over LSP

Completion with auto-import, Quick Documentation, diagnostics and navigation. Configurable profiles, with jdtls as the first one.

Alt+1 · Alt+9

The IDE layout you know

Project pane, editor tabs and tool window stripes around them, with resizable splitters. No window to open.

JGit

Commit from the shell

Stage or unstage files, write multiline messages and amend after reviewing the staged-change summary. Git through JGit.

Alt+4

Run the application

Detects Quarkus, Spring Boot and configured Java commands, keeps the choice per project, and runs Maven or Gradle goals.

ACP · MCP

AI agents, both ways

Run OpenCode, Claude Code or pi in a side panel over ACP. Other agents drive the shell through the MCP server.

Ctrl+T

Familiar keys and colors

The intellij keymap is the default, and the themes come from IntelliJ IDEA's own color files.

Try it

No published binary yet. The installer clones the repository, builds it and installs the vintelli command. You need git and JDK 25. With GraalVM or Mandrel it builds a native binary that needs no JVM.

bash
$ curl -fsSL https://raw.githubusercontent.com/omatheusmesmo/vintelli/main/scripts/install.sh | bash
$ cd your-java-project
$ vintelli
