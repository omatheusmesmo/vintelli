A terminal IDE for Java with an IntelliJ IDEA-like layout. It runs with open tooling only. IntelliJ IDEA is an optional extra.

Standalone first

Vintelli works without IntelliJ IDEA. Every capability has a standalone provider, and IDEA only adds its providers for Run, Terminal, Problems and call hierarchy when you connect it.

What it does

  • Work where you already are. A full IDE layout in your terminal, with no window to open.
  • Native when you want it. With a GraalVM or Mandrel toolchain, the installer builds one binary that needs no JVM to run.
  • Open tools by default. Maven, Gradle, terminal commands and Git (JGit) need no IDE.
  • Commit from the shell. Stage or unstage the selected project file, write multiline commit messages, and amend the current commit after reviewing the staged-change summary.
  • Start the application. Detect Quarkus, Spring Boot and configured Java application commands, and keep the choice per project.
  • AI agents in a side panel. Choose OpenCode, Claude Code or pi over ACP, with executable availability shown before a session starts.
  • Other agents can drive it. The MCP server reads the shell state and pushes highlights and diffs into the TUI.
  • Language support over LSP. Configurable profiles, with jdtls as the first one.
  • Familiar keys and colors. The intellij keymap is the default, and the themes come from IntelliJ IDEA's color files.

Try it

Vintelli is pre-release and has no published binary yet. The installer clones the repository, builds it and installs the vintelli command. You need git and JDK 25.

curl -fsSL https://raw.githubusercontent.com/omatheusmesmo/vintelli/main/scripts/install.sh | bash
cd your-java-project
vintelli
